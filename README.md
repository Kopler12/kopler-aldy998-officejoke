## The joke

> Our printer got promoted to manager — ten years of jamming, blaming IT, and taking credit for everyone else's work, and HR called it management material.

## How it works

`main.py` writes the joke to `/output/entry.txt` (one line, 153 characters, plain UTF-8 text). Nothing else is needed: the writing is the whole contest.

Run it with:

```sh
python3 main.py
```
